# asset

1~16번 운동의 대표 이미지(.jpg 16장)를 넣는 폴더입니다.
17~300번 운동은 원본 저장소(Free Exercise DB)의 이미지 주소(`exercises/<sourceId>/0.jpg`)를 사용합니다.
(GitHub 웹 업로드는 한 번에 100개까지라 284장을 폴더에 넣지 않고 주소로 불러옵니다.)

원본 이미지는 비율이 제각각이라, 상세 화면에서는 사진 전체가 보이도록 맞추고(`object-fit: contain`) 남는 부분은 같은 사진을 흐리게 깔아 채웁니다.

이미지 출처: Free Exercise DB (https://github.com/yuhonas/free-exercise-db)
