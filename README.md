### coreseek_v0.5 (2026-11-16)

**추가**
- 오른쪽 위 **로그인 버튼**: 누르면 로그인 / 회원가입 창이 열림. 로그인하면 **로그아웃 버튼**으로 바뀌고, 누르면 바로 로그아웃
- 로그인, 가입, 로그아웃 때 화면 아래에 짧은 알림 표시
- `pages/prototype_v0.5/index.html`: 프로토타입 v0.5 보관본 (CSS, JS, 데이터를 파일 하나에 포함)
- `pages/index.html`: 보관본 목록 페이지
- 회원가입: 로그인 창의 회원가입 탭. 아이디(영문 소문자, 숫자, 밑줄 4~20자), 비밀번호(영문과 숫자를 섞어 8자 이상), 비밀번호 확인
- 로그인: 아이디, 비밀번호로 로그인. 새로고침해도 로그인 상태 유지
- 입력 오류 안내: 짧은 아이디, 약한 비밀번호, 비밀번호 확인 불일치, 이미 있는 아이디, 틀린 비밀번호, 연결 실패
- 계정 저장 방식 두 가지: 기본은 브라우저 저장(localStorage). `js/app.js`의 `SHEET_URL`에 주소를 넣으면 구글 시트에 저장
- 비밀번호 보호: 비밀번호를 그대로 저장하지 않고, 무작위 값(salt)을 섞어 SHA-256 해시로 저장
- `server/Code.gs`, `server/README.md`: 구글 시트 연동용 Apps Script 코드와 연결 방법

**변경**
- 홈 첫 화면: 소개 박스와 "오늘은 어디를 운동할까요?" 부위 바로가기가 따로 있음 → 질문, 검색창, 부위 버튼을 **한 블록으로 합침** (부위 버튼은 3열 큰 버튼)
- 홈 소개 문구: "헬스장이 처음이라면, 코어시크 / 운동 이름을 몰라도 괜찮아요. 운동할 부위나 기구만 고르면 …" → "오늘은 어디를 운동할까요? / 부위를 고르거나 운동을 검색하세요"
- 홈 검색창 문구: "어떤 운동을 찾고 있나요?" → "운동 검색"

- 누르는 느낌: 카드, 타일, 칩, 버튼, 순위 줄을 누르면 살짝 작아지는 효과
- `index.html`의 CSS, JS 버전 번호: `20261109g` → `20261116d`

**삭제**

# 2. PRD

## 2.1 한 줄 소개

헬스장에 처음 가는 사람이 운동 이름을 몰라도, 운동할 부위나 기구만 고르면 하는 방법과 조심할 점을 바로 찾을 수 있는 운동 안내 웹서비스입니다.

---

## 2.2 배경과 문제

헬스장에 처음 가면 기구는 많은데 이름도 모르고 쓰는 법도 모릅니다. 검색을 하려 해도 "랫풀다운", "시티드 로우" 같은 운동 이름을 알아야 찾을 수 있어서, 결국 익숙한 러닝머신만 타다 돌아오는 경우가 많습니다.

우리가 풀려는 문제는 세 가지입니다.

1. **이름을 몰라서 못 찾는다.** 대부분의 운동 정보는 운동 이름으로 검색해야 나옵니다.
2. **나에게 맞는지 모른다.** 초보자가 해도 되는지, 지금 비어 있는 기구로 할 수 있는지 판단하기 어렵습니다.
3. **어떻게 하는지 모른다.** 영어 자료가 많고, 기구를 어떻게 맞추는지와 무엇을 조심해야 하는지가 빠져 있는 경우가 많습니다.

---

## 2.3 목표

| 목표 | 확인 방법 |
|---|---|
| 운동 이름을 몰라도 원하는 운동에 도착한다 | 홈에서 부위 하나를 누르고 운동 카드 하나를 누르면, 두 번 만에 운동 방법 화면이 열린다 |
| 초보자에게 맞는 운동이 먼저 보인다 | 탐색 화면의 기본 정렬이 초보자 추천순이고, 홈 추천 운동은 모두 초급이다 |
| 조건을 너무 좁혀도 막히지 않는다 | 결과가 0개일 때 어떤 조건을 빼면 몇 개가 나오는지 알려 주는 버튼이 항상 나온다 |
| 하는 방법을 우리말로 읽을 수 있다 | 운동 300개 모두 우리말 운동 순서가 있다 |

---

## 2.4 타깃 사용자

**주 사용자: 헬스장 등록 1~3개월 차 초보자**

- 운동 이름은 거의 모르지만 "오늘은 가슴", "오늘은 하체"처럼 부위는 정할 수 있다
- 트레이너 없이 혼자 운동한다
- 휴대폰으로 헬스장 안에서 바로 찾아본다

**가상 사용자 예시** (이해를 돕기 위해 만든 인물입니다)

> 지수, 24세, 대학생. 헬스장에 등록한 지 2주가 됐다. 친구가 등 운동으로 랫풀다운을 하라고 했는데 기구 앞에서 의자 높이를 어떻게 맞추는지 몰라 그냥 지나쳤다. 머신이 비어 있을 때 바로 휴대폰으로 방법을 보고 싶다.

## 2.5 사용 흐름

```
홈
 ├─ 부위 고르기 (가슴, 등, 하체, 어깨, 팔, 복근)  ─┐
 ├─ 검색창에 입력하고 Enter                         ├─→ 탐색
 ├─ 많이 찾는 운동 순위에서 고르기  ─────────────────┼─→ 운동 상세
 └─ 처음이라면 이 운동부터에서 고르기  ──────────────┘
탐색
 ├─ 난이도, 기구, 조건으로 좁히기
 ├─ 정렬 바꾸기
 └─ 운동 카드 누르기  ─→ 운동 상세
운동 상세
 ├─ 쓰는 근육, 기구 맞추기, 운동 순서, 조심할 점 보기
 ├─ 저장하기  ─→ 보관함
 ├─ 후기 남기기
 └─ 기구가 사용 중이면 목록으로 돌아가 다른 기구 고르기
```

## 2.8 탐색 규칙

### 검색
- 찾는 범위: 운동 이름, 영문 이름, 부위, 기구, 쓰는 근육
- 띄어쓰기와 대소문자를 무시합니다. "스쿼트", " 스 쿼 트 ", "SQUAT"의 결과가 같습니다
- 검색어가 비어 있으면 전체를 보여 줍니다

### 필터
같은 묶음 안에서는 하나만 맞아도 나오고(OR), 묶음끼리와 조건끼리는 모두 맞아야 나옵니다(AND).

| 묶음 | 고를 수 있는 값 | 기준 필드 |
|---|---|---|
| 부위 | 가슴, 등, 하체, 어깨, 팔, 복근 | category |
| 난이도 | 초급, 중급 | difficulty |
| 기구 | 맨몸, 머신, 덤벨, 바벨 | equipment |

| 조건 버튼 | 기준 | 통과 조건 |
|---|---|---|
| 설명이 있는 운동 | description | 값이 있음 |
| 미는 운동 | force (외부 데이터) | 밀기 |
| 당기는 운동 | force (외부 데이터) | 당기기 |
| 여러 근육 같이 | mechanic (외부 데이터) | 복합 |
| 한 부위만 집중 | mechanic (외부 데이터) | 고립 |

외부 데이터를 불러오지 못하면 아래 네 조건 버튼은 꺼지고, 다시 불러오기 버튼이 나옵니다.

### 정렬
| 정렬 | 기준 |
|---|---|
| 초보자 추천순 (기본) | 초급, 머신이나 맨몸, 설명이 있는 운동일수록 앞. 같으면 많이 찾는 순, 그다음 이름순 |
| 많이 찾는 순 | popularity가 큰 순 |
| 별점 높은 순 | 후기 평균 별점이 높은 순. 후기가 없으면 뒤로 |
| 쉬운 운동부터 | 초급 다음 중급 |
| 이름 가나다순 | 운동 이름 |

정렬은 결과 목록에만 적용하고 원본 데이터 순서는 바꾸지 않습니다.

### 결과 없음과 초기화
- 결과가 0개면 마지막에 고른 조건부터 하나씩 빼 보고, 결과가 생기는 조건을 "OO 조건을 빼면 N개가 나와요"와 버튼으로 알려 줍니다
- 초기화를 누르면 검색어, 부위, 난이도, 기구, 조건, 정렬이 모두 기본값으로 돌아가고 300개가 다시 보입니다
- 데이터를 불러오지 못했을 때는 결과 없음과 다른 화면과 문구로 안내합니다

## 2.9 데이터

### 규모
운동 300개. 부위마다 50개씩이고, 초급 219개와 중급 81개, 기구는 머신 109개, 바벨 68개, 덤벨 63개, 맨몸 60개입니다.

### 출처와 구분
| 내용 | 출처 | 구분 |
|---|---|---|
| 이름, 영문 이름, 부위, 난이도, 기구, 운동 순서, 사진 | Free Exercise DB (퍼블릭 도메인) | 실제 |
| 쓰는 근육, 동작 유형 | Free Exercise DB를 화면이 열릴 때 불러옴 | 실제 |
| 1~16번 설명, 기구 맞추기, 조심할 점 | 수업 실습용으로 AI가 쓴 글 | 더미 |
| popularity (많이 찾는 수치) | 수업 실습용 예시 값 | 더미 |
| sampleReviews (1~16번 예시 후기 2개씩) | 수업 실습용 예시 글 | 더미 |
| 사용자가 남긴 저장, 최근 본 운동, 후기 | 사용자의 브라우저 | 이 기기에만 저장 |
| 회원 계정 (아이디, salt, 비밀번호 해시) | 브라우저 저장, 또는 구글 시트 (Apps Script) | 실제 사용자 입력 |

각 운동의 `meta` 필드에 실제(real), 더미(dummy), 비어 있음(unknown)을 기록해 두었고, 화면에서도 실제와 더미 표시를 붙여 보여 줍니다. 필드별 설명은 `data/README.md`에 있습니다.

## 2.10 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 화면 크기 | 휴대폰 360px에서도 가로로 넘치지 않음 |
| 테마 | 기기 설정에 따라 라이트와 다크 모드 모두 지원 |
| 불러오는 중과 실패 | 데이터를 불러오는 중, 불러오기 실패, 외부 데이터 실패를 각각 다른 문구로 안내 |
| 새 버전 반영 | CSS와 JS 주소에 버전 번호를 붙여 업로드 후 바로 새 화면이 보이게 함 |
| 접근성 | 조건 버튼의 선택 상태를 aria-pressed로 알리고, 아이콘 버튼에 aria-label을 붙임. 순위 줄은 키보드로도 열 수 있음 |
| 계정 보안 | 비밀번호는 salt를 섞은 SHA-256 해시로만 저장. 수업용 프로토타입이라 로그인 시도 제한, 비밀번호 찾기는 아직 없음 |
| 실행 환경 | GitHub Pages에서 동작. 내려받아 볼 때는 Live Server 사용 |
