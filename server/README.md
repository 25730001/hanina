# server

회원가입과 로그인 정보를 **구글 시트**에 저장할 때 쓰는 코드입니다.

`js/app.js`의 `SHEET_URL`이 비어 있으면 계정은 사용자의 브라우저에만 저장되고, 이 서버는 쓰이지 않습니다. 여러 기기와 여러 사람이 같은 계정 목록을 쓰려면 아래 순서대로 연결합니다.

## 연결 순서 (약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름은 `coreseek-users`처럼 정합니다.
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 `https://script.google.com/macros/s/…/exec` 주소가 나옵니다.
6. 그 주소를 브라우저에서 열어 `코어시크 계정 서버가 동작 중이에요.`가 보이는지 확인합니다.
7. `js/app.js`에서 아래 줄에 주소를 넣고 GitHub에 올립니다.
   ```js
   var SHEET_URL = "https://script.google.com/macros/s/…/exec";
   ```
8. 사이트에서 회원가입을 하면 시트에 `users` 탭이 생기고 한 줄이 추가됩니다.

## 시트에 저장되는 값

| 열 | 내용 |
|---|---|
| id | 아이디 |
| salt | 비밀번호에 섞는 무작위 값 |
| hash | salt와 비밀번호를 합쳐 SHA-256으로 바꾼 값. **비밀번호 자체는 저장하지 않습니다** |
| createdAt | 가입한 시각 |
| lastLoginAt | 마지막으로 로그인한 시각 |

## 주의

- 수업용 프로토타입입니다. 실제 서비스 수준의 보안(로그인 시도 제한, 비밀번호 찾기, 토큰 인증 등)은 들어 있지 않습니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
- 시트는 팀원에게만 공유하고, 공개 링크로 공유하지 않습니다.
